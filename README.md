# 一键清理缓存 / Cache Cleaner

Windows 单文件缓存清理工具。双击即用，不需要安装任何依赖，也不需要任何配套文件。

## 用法

```
双击运行                      扫描后进入选择界面，回车即清理默认项
一键清理缓存.bat -DryRun       只扫描，不删除任何文件
一键清理缓存.bat -Yes          跳过选择，直接清理默认项
一键清理缓存.bat -IncludeAdmin 额外列出需要管理员权限的项目
一键清理缓存.bat -MinAgeDays 7 只清理 7 天之前的文件
一键清理缓存.bat -NoPause      结束时不等待按键
一键清理缓存.bat -Report       只列出疑似残留的用户目录（只读，不删除）
```

选择界面支持：回车（默认项）、`1,3,5`（指定编号）、`A`（全部）、`N`（退出）。
涉及注册表或用户目录的项目需要先输入 `DELETE` 二次确认。

## 可清理项

| # | 项目 | 默认 |
|---|---|---|
| 1 | 用户 Temp | 是 |
| 2 | Updater 更新缓存 | 是 |
| 3 | 包管理器缓存（npm / pnpm / yarn / bun / pip / uv） | 是 |
| 4 | pnpm store 瘦身 | 是 |
| 5 | 浏览器缓存（Chrome / Edge） | 是 |
| 6 | Windows 错误报告 | 是 |
| 7 | 缩略图/图标缓存 | 是 |
| 8 | 回收站 | 否 |
| 9 | 残留快捷方式 | 否 |
| 10 | 打开方式残留 | 否 |
| 11 | 卸载表残留 | 否 |
| 12 | 旧版本残留（Electron） | 否 |
| 13-16 | Windows 更新缓存 / 传递优化 / 系统 Temp / Windows.old | 否，需管理员 |

第 13-16 项在以管理员身份运行时自动列出。

## 安全设计

- **先扫描后删除**，默认项之外一律不勾选，所有破坏性操作都要显式选择
- 删除失败**不静默**：被占用或无权限的文件会统计成"跳过 N 个"并显示出来
- pnpm 用 `pnpm store prune`，只删没有项目引用的包，不影响现有项目
- 只认固定的缓存路径，不扫 AppData 整棵树，不碰任何项目目录

## 刻意不做的事

以下类别删除代价过大或风险过高，工具一律不处理，避免误伤：

- AI 模型缓存（Ollama / HuggingFace）、Maven `~/.m2`、Gradle 缓存
- 微信等**应用自身的缓存**（聊天记录与缓存目录同级并列，误判代价不可接受）
- Windows Installer 缓存（删除后已装程序无法修复/卸载）
- WinSxS 组件存储（需用 `DISM`，风险更高）
- 卸载后残留的用户目录——只用 `-Report` 列出供人工判断，**不自动删除**

## 实现说明

整个工具是单个 .bat，PowerShell 主体以 base64 存放在文件末尾（每行 `REM #B64#` + 100 字符），运行时解码执行。

这么做是因为 cmd 的一个已知缺陷：**含中文的 UTF-8 批处理文件，cmd 分块读取时会把注释行里的中文片段当成命令执行**，导致脚本一闪而过。把文件保持 100% 纯 ASCII（最大字节值 126）可以彻底规避。代价是源码在文件里不可读，改内容需要先解码 `REM #B64#` 行。

同理，`.lnk` 快捷方式的目标是直接用二进制解析的，不依赖 `WScript.Shell`；旧格式 .lnk 的路径以系统 ANSI 代码页存储，需按代码页解码而非逐字节转字符。
